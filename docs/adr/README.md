# DJQBox — Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for DJQBox. Each ADR documents a significant architectural decision: its context, the decision made, the alternatives considered, and the consequences.

ADRs are append-only. To change a past decision, create a new ADR that supersedes the old one and update the old ADR's status to `Superseded by ADR-NNN`.
